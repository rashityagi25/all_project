# Metro Travel App

## 
Individual Full Stack Web Application

---

## Project Description
Metro Travel App is a Java-based web application that simulates a real-world metro system.  
It allows users to register, log in, plan routes, book tickets, recharge metro cards, and view booking history.

This project focuses on the practical implementation of **Data Structures and Algorithms** in a real-world scenario.

---

## Objective
The main objective of this project is to design and develop a metro system simulation using Java technologies and implement data structures like Graph, Queue, and HashMap along with Dijkstra’s Algorithm for shortest path calculation.

##  Data Structures & Algorithms Used

| Concept | Usage |
|--------|------|
| Graph | Represents metro network |
| Dijkstra Algorithm | Finds shortest path |
| Queue | Manages ticket booking requests |
| Priority Queue | Used in Dijkstra Algorithm |
| HashMap | Efficient data handling |

##  Features

- User Registration & Login
- Route Planning System
- Shortest Path Calculation
- Ticket Booking System
- Metro Card Recharge
- Booking History
- Fare Calculation
- Queue-based Booking Handling

---

##  Project Workflow

1. User registers and logs in  
2. Selects source and destination  
3. System calculates shortest route using Dijkstra Algorithm  
4. User books ticket  
5. Fare is deducted from metro card  
6. User can recharge card  
7. Booking history is stored and displayed
